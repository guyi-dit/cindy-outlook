# Microsoft Outlook（Hotmail）Cindy 插件

独立连接 Hotmail / Outlook.com / Live。只申请邮件权限，授权在 Cindy 里完成。

## 能做什么

- 搜索邮件、查看最近收件箱
- 阅读正文
- 列出全部文件夹（含子文件夹）
- 按名称 / path / id 移动邮件
- 列出、下载邮件附件
- 把你发来的本地文件作为邮件附件发出或存草稿（需明确说发送）
- 删除邮件（需明确说删除）

## 安装

Cindy → 「+ 添加插件」→「安装插件...」→ 选择 microsoft-outlook.cindy。
装好后打开插件详情页，点「连接账号」，用 Hotmail 登录。
