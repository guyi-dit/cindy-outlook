Outlook 账号 独立授权

支持 Hotmail、Outlook.com、Live。只申请邮件读写与发送权限，不会读取 OneDrive / 日历。

首次连接前需要 Azure 应用 ID

Cindy 官方还没有 Microsoft 应用身份，所以要用你的 Hotmail 免费注册一个「公共客户端」：

  1. 打开 Azure 应用注册：https://portal.azure.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade
  2. 新注册。帐户类型选「仅个人 Microsoft 帐户」。重定向 URI 先可留空。
  3. 打开「清单 / Manifest」，在 replyUrlsWithType 里加入： {"url":"http://127.0.0.1:53683/callback","type":"InstalledClient"}
  4. 同一清单里把 allowPublicClient 设为 true。
  5. 复制 Overview 页的 Application (client) ID，在本插件目录运行 python3 scripts/set-client-id.py <client-id> 然后在 Cindy 插件市场刷新「我的插件」。
